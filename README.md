# 한 걸음 영어 · 카페 교실

서울 디지털 동행 플라자 동대문센터 시니어 수업을 위한 스마트폰 중심의 생활 영어 학습 사이트입니다. 공식 센터 홈페이지가 아닌 수업용 자료입니다.

## 제공 기능
- 카페 미션 3개, 각 5단계: 음료 주문 / 크기와 온도 / 포장과 결제
- 모든 질문과 답변에 영어, 한글 발음, 한국어 뜻
- 보고 따라 하기 / 골라서 대답하기 / 혼자 말해 보기
- 기기의 영어 음성으로 듣기, 천천히 듣기, 중지
- 선택한 음료·크기·온도를 반영한 주문 확인 문장
- 선택한 대화 복습, 도움 요청 영어, 글자 확대
- 브라우저에 진도와 완료 기록 저장, 기록 초기화

## 범위
실시간 AI, API, 로그인, 음성 녹음, 음성 인식, 발음 평가, 분석 추적은 없습니다. '소리 내어 말했어요'는 학습자 자기 확인입니다. 음성은 Web Speech API의 speechSynthesis를 이용합니다. 목소리와 지원 여부는 기기·브라우저·설치된 음성에 따라 달라집니다. 오프라인 동작이나 동일한 발음 품질은 보장하지 않습니다. 음성 서비스가 네트워크를 사용할 수 있습니다. 한글 발음은 참고용입니다. 결제 금액은 가상의 연습 예시입니다.

## 파일
- index.html: 기본 화면 틀
- style.css: 스마트폰 화면 및 접근성 스타일
- data.js: 수정 가능한 대화 자료
- app.js: 학습 흐름, 음성 재생, 기록 저장
- .nojekyll: GitHub Pages 정적 배포

## GitHub Pages 배포
1. GitHub에서 `cafe-english`라는 공개 저장소를 만듭니다. 이미 같은 이름이 있으면 다른 이름을 사용합니다.
2. 이 폴더의 index.html, style.css, data.js, app.js, README.md, .nojekyll을 저장소 루트에 올립니다. ZIP 파일 자체를 올리는 것이 아닙니다.
3. Settings → Pages → Build and deployment에서 'Deploy from a branch'를 선택합니다.
4. main 브랜치, /(root)를 선택한 후 Save를 누릅니다.
5. 배포 완료 후 GitHub가 표시하는 사이트 URL을 수강생에게 공유합니다.

`.openai/hosting.json`은 개발 미리보기용이며 GitHub에 업로드할 필요가 없습니다. 외부 라이브러리나 빌드 과정은 필요하지 않습니다. URL은 상대 경로를 사용해 프로젝트 Pages 하위 경로에서도 동작합니다.

## 수업 전 기기 점검
안드로이드 Chrome과 iPhone Safari 실제 기기로 확인합니다. 이어폰, 미디어 음량, 듣기/느리게/멈춤, 큰 글자, 미션 완료, 이어 하기, 초기화를 확인합니다. 브라우저 자동화만으로 실제 발음이나 기기 음성을 확인할 수는 없습니다.

## 운영
학습 정보는 `cafe-english-v1` 키로 localStorage에만 저장됩니다. 공용 기기는 기록을 초기화합니다. 선택지를 수정하면 이전 진도와 호환되도록 저장 데이터 검증을 유지하거나 키 버전을 올립니다. 대화 내용은 기기의 읽어 주기 기능 이외의 외부 서비스로 전송하지 않습니다.

## 제작 시 검증
- JavaScript 구문 검사 통과
- 15단계의 질문·답변 발음/번역 데이터 검사 통과
- 음료 3종 × 크기 3종 × 온도 2종 = 주문 확인 18조합 검사 통과
- 브라우저에서 세 미션을 끝까지 진행하고 복습·완료 기록 확인
- 새로고침 후 이어 하기, 큰 글자 유지, 혼자 말하기 예시 숨김, 도움말, 기록 초기화 확인
- 390px 및 320px 프레임에서 화면 확인; 320px 큰 글자 학습 화면에서 가로 넘침 없음
- 실제 스마트폰 음성 출력 품질은 미검증
